# Práctica 1 - Creación de clases y encapsulamiento en PHP
## Objetivo
Aplicar los fundamentos de la Programación Orientada a
Objetos en PHP, implementando una clase con atributos privados,
constructor y métodos de acceso, siguiendo buenas prácticas de
encapsulamiento.
## Descripción de la clase creada
Se creo una clase con el nombre de Usuario, con dos atributos privados, nombre y correo,
se utilizaron los métodos setter y getter para trabajar con los atributos, también contiene
un construtor que imprime un mensaje cuando se crea el objeto.

## Instrucciones de ejecución
Incluir en el index.php el archivo que contiene la clase en este caso es Usuario.php ya sea 
con "include" o con "require_once", después se crea una instancia de la clase en el mismo archivo,
posteriormente se asignan valores al nombre y al correo utilizando los métodos setters, para después mostrarlos en el navegador con los métodos getters.
